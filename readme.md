# Crumble Cafe 🥐

Одностраничный сайт-визитка кафе, собранный с использованием **Webpack 5** и **Vanilla JavaScript** (без фреймворков). Весь контент (навигация, меню, контакты, формы) генерируется динамически через JS-модули без перезагрузки страницы.

## 🚀 Как запустить проект

1. Установите зависимости:
   ```bash
   npm install
   Запустите сервер для разработки:

bash
npm start
Проект откроется автоматически в браузере по адресу: http://localhost:8080

Соберите проект для продакшена (создаст папку dist/ с оптимизированными и хешированными файлами):

bash
npm run build
✅ Какие задания выполнены
Уровень 1. Базовые доработки
[1.1] Вкладка «Контакты»: Создан модуль contact.js. Добавлен адрес, телефон, часы работы и ссылка на соцсеть. Навигация работает без перезагрузки страницы.

[1.2] Стилизация: Создан style.css. Добавлен фон для body, стили для кнопок с hover-эффектом, а также подключен нестандартный шрифт (через Google Fonts @import).

[1.3] Активная вкладка: При клике на кнопку ей добавляется класс .active (жирный шрифт + подчеркивание). У остальных кнопок этот класс убирается.

Уровень 2. Работа с контентом и данными
[2.1] Данные меню в JSON: Создан файл menu-data.json. Данные импортируются в menu.js, и карточки блюд генерируются через цикл forEach.

[2.2] Изображения блюд: Картинки добавлены в src/images/. Настроены asset modules в webpack.config.js (правило type: 'asset/resource'). Изображения импортируются в JS и корректно собираются в dist/.

[2.3] Кнопка «Забронировать столик»: Добавлена на вкладке «Контакты». При клике вызывает alert() с сообщением об успешной брони.

Уровень 3. Интерактивность и UX
[3.1] Форма обратной связи с валидацией: На вкладке «Контакты» добавлена форма (Имя, Email, Сообщение).

Имя проверяется на минимальную длину (2 символа).

Email проверяется через регулярное выражение.

При ошибке поля подсвечиваются красным, выводится текст ошибки. При успехе — alert() с благодарностью и очистка формы.

[3.2] Счётчик посещений: Счетчик открытий вкладки «Меню» сохраняется в localStorage и выводится на экран (сохраняется после перезагрузки).

[3.3] Плавная анимация: Добавлен @keyframes fadeIn в CSS. Класс .tab-content применяет анимацию появления контента (плавное появление и сдвиг вверх).

Дополнительно (Задание 4.2)
Хеширование файлов: В webpack.config.js настроен output.filename с [contenthash] для продакшн-сборки. При выполнении npm run build файлы в dist/ получают уникальные хеши (например, main.a1b2c3d4.js), что оптимизирует кеширование.
